## 2. Guidelines for Contributions

1. **Architecture & Standards:** Follow PEP 8 guidelines for Python backend code and strict TypeScript / Svelte 5 runes conventions for the WebUI.
2. **Quality & Validation:** Ensure all new features, bug fixes, and documentation adhere to project conventions, pass local validation checks, and maintain code quality before opening a Pull Request.
3. **Licensing Integrity:** Do not introduce third-party code with conflicting licenses (such as GPL/AGPL copyleft libraries) that would restrict BSL 1.1 or Apache 2.0 distribution.
4. **Commit Messages:** Use clear, descriptive commit messages following the [Conventional Commits](https://www.conventionalcommits.org/) format (e.g., `feat: ...`, `fix: ...`, `docs: ...`, `test: ...`).
